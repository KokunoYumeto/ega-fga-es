FGA es obra de Alexandre Grothendieck. Esta edición española independiente reúne las ocho exposiciones del Seminario Bourbaki, sus ocho textos de erratas y los comentarios de 1962. La colección incluye además ediciones parciales de EGA, de Alexandre Grothendieck con la colaboración de Jean Dieudonné; esta publicación no declara completa la traducción de EGA.

El lector actual incorpora las correcciones admitidas. La traducción según el impreso de la exposición 149 conserva los errores realmente impresos y distingue las reparaciones de transcripción comprobadas. Las dos ramas no son intercambiables. Las ediciones y todos los archivos heredados permanecen accesibles.

LaTeX es el principal original editable. Cada PDF tiene su fuente completa directamente descargable y un ZIP propio con el proyecto modular, los estilos, las dependencias específicas y las instrucciones de reconstrucción. Los paquetes y las fuentes tipográficas estándar de TeX son dependencias del entorno documentadas en cada ZIP.

Las formas modular y acumulativa de los cuatro lectores producen PDF idénticos en las compilaciones de comprobación y sus repeticiones. Se verificaron fórmulas, estructura y enlaces, y se inspeccionaron visualmente 26 páginas distintas de portadas, notas, pasajes modificados y transiciones. No se afirma una revisión humana ni la ausencia de toda advertencia de composición.

Contribución de IA: integración de correcciones, comprobación de lectores y preparación de esta publicación por OpenAI Codex — GPT-6 Astra, esfuerzo Ultra. El modelo y el esfuerzo de todas las traducciones heredadas no están identificados con certeza. La integración anterior de EGA III-1 se atribuyó a OpenAI Codex — GPT-5.6 Sol, esfuerzo Ultra. La autoría matemática corresponde a los autores originales; no se atribuye a ellos revisión de estas traducciones.
