# Historical III translation templates

These scripts preserve the Spanish source-bound translations and explicit decisions used during the audit. They refer to the working layout and to intermediate alignment states. They are not an idempotent migration and must not be run sequentially against the completed edition.

Use `audit_iii_alignment.py`, `iii_final_math.py`, `iii_final_markers.py` and `finish_iii_records.py` for final source-fidelity checks and records. The completed Spanish text and the before/after change records are authoritative deliverables. The root task owns reader compilation and PDF checks.
